# Ikidone (formerly Slack Tasks): installers and updates

This repository only holds the Ikidone installers. The source code is private.

Ikidone checks this repository for new versions (`latest.json` in the newest release) and
updates itself when you click **Update to …** in its menu. Every update is signed, and the app
refuses files that aren't.

## Install

Open the [latest release](../../releases/latest) and download, for your computer:

- **Mac (Apple Silicon):** the `.dmg`, `Install-Ikidone.command` and `How-to-install-Mac.txt`
- **Windows:** the `-setup.exe`, `Install-Slack-Tasks-Windows.bat`, `install-windows.ps1` and
  `How-to-install-Windows.txt`

Put them in one folder and follow the How to install file.

New to Ikidone? **[Start here](GUIDE.md)**: install, connect your apps and make your first email
report, on one page.
